# Estratégia, segmentação e jornada

Para quando a pessoa ainda não tem isso claro. Use só o que ajudar agora. Melhor uma versão simples hoje do que um desenho completo que ninguém usa. O crédito de cada ideia está em `CREDITOS.md`, na raiz do plugin.

## Por onde começar

Uma ordem que funciona: entender quem é o cliente, agrupar, desenhar a jornada, organizar os dados, medir e refazer. Nos primeiros 90 dias de uma área nova, primeiro entenda o negócio e os envolvidos, defina sucesso e olhe a maturidade. As prioridades vêm depois.

A estrutura muda com a fase da empresa. No começo vendas cuida; depois vem a primeira pessoa de CS; só então fazem sentido segmentação e governança. Não venda para uma empresa de 30 clientes o desenho de uma de 3 mil.

## Segmentação

A skill sugere e confirma com a pessoa. Três eixos: valor pago, encaixe com a ferramenta e objetivo do cliente. Para cada grupo, defina o nível de atendimento, do um para um até o automático. Pergunte quanta receita ou quantas contas cada pessoa do time aguenta.

## Encaixe ruim (bad fit)

Um sinal forte é o cliente usar o sistema para algo que funciona, mas não é a base dele, e isso gera muito chamado. Exemplo: uma revendedora de medicamentos que quer controlar estoque num sistema feito para clínica. Os tipos de encaixe ruim: técnico, funcional, de suporte, de experiência, de cultura e financeiro.

Um filtro simples: hipóteses, variáveis, dados, nota de A a D, e cruzar com o churn. Duas perguntas para as outras áreas: quem dá mais trabalho e deixa pouco dinheiro? Quem tem objetivo diferente do que o software entrega como base?

## Jornada

Desenhe pela experiência do cliente, não pelas etapas do contrato. Faça em três passadas: hipótese, entrevistas e números. Entreviste também quem cancelou.

Para cada etapa, preencha:

| campo | o que responde |
| --- | --- |
| validação | como sei que o cliente passou? |
| atividades obrigatórias | o que precisa acontecer? |
| prazo | quanto tempo até considerar parado? |
| tratativa | o que fazer quando empaca? |
| criticidade | quanto isso pesa se der errado? |
| canal | por onde falamos? |
| motivo para continuar | por que o cliente segue? |
| obstáculos comuns | onde costuma travar? |

**O prazo é o coração.** A conta parada além do prazo é o que avisa antes. Comece com uma hipótese e calibre depois, comparando o tempo até o primeiro valor de quem ficou com o de quem cancelou. Prazo de outra empresa não serve de regra.

## Regras práticas do onboarding

- Sem OK do cliente, a etapa não fecha.
- Treine por rotina, não por módulo.
- Capacitar não é entregar.
- O vendedor participa do kickoff.
- Registre os papéis: patrocinador, usuário-chave, gerente, financeiro.
- Separe "pendência do cliente" de "parado por nós". É o que define quem precisa agir.

Na passagem de bastão de vendas para o CS, peça pelo menos: motivo da compra, patrocinador e usuário-chave, o que vai usar de fato, como trabalha hoje e qual a maior dificuldade, e o que foi prometido. O motivo da compra é o dado mais caro da conta e o primeiro que se perde.
